# Shardbound
A standalone isometric survival adventure for mobile and desktop. Fight three waves of hunters, shooters, and charging sentinels before each guardian. Build combo scores, collect healing shards, and choose a new skill after each island. No dependencies or build step.

Mobile: joystick, hold Strike, tap Dash, and activate Nova when fully charged. Desktop: WASD/arrows, Space, Shift, E. Every third strike is a finisher; dashes damage enemies; Nova clears nearby enemies and projectiles. Orbiting shards and chain lightning unlock as guardian rewards. Optional synthesized audio starts only after enabling sound. Best island is saved locally.

Deploy: push these files, including .github/workflows/deploy.yml, to main in sirioitalianfactory/shardbound. Uses the same GitHub Actions → GitHub Pages workflow as Sky Break. Expected address after a successful deployment: https://sirioitalianfactory.github.io/shardbound/

## Blender artwork
The island and four-direction character sprites are modeled, lit, and rendered in Blender. `art/build_assets.py` recreates all PNG renders: `blender -b --python art/build_assets.py`. Convert PNGs in assets to WebP with Pillow (quality=90, method=6) before publishing. The runtime uses 14 transparent WebP images, totaling approximately 120 KB. Rendering is 2D canvas with pre-rendered 3D assets; no WebGL or external runtime dependencies.

The hero, floating sentinels, guardian, ancient island, vegetation, arch, and crystal models are generated by the source script. Directional sprites, idle movement, blade trails, pickup glow, and boss wind-up effects animate in the browser.
