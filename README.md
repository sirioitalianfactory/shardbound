# Shardbound
A standalone isometric survival adventure for mobile and desktop. Collect shards, defeat guardians, and choose an upgrade after each island. No dependencies or build step.

Mobile: joystick, hold Strike, tap Dash. Desktop: WASD/arrows, Space, Shift. Optional synthesized audio starts only after enabling sound. Best island is saved locally.

Deploy: push these files, including .github/workflows/deploy.yml, to main in sirioitalianfactory/shardbound. Uses the same GitHub Actions → GitHub Pages workflow as Sky Break. Expected address after a successful deployment: https://sirioitalianfactory.github.io/shardbound/
